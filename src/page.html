Hướng dẫn cài đặt DNS

Cấu hình DNS trỏ về IP thiết bị này để kích hoạt chặn quảng cáo cho toàn mạng hoặc từng máy.

Cài đặt trên Router / Modem Wi-Fi (Chặn toàn bộ thiết bị trong nhà — Khuyên dùng)

  1. Mở trình duyệt, đăng nhập vào trang quản trị Modem/Router Wi-Fi của bạn (thường là 192.168.1.1 hoặc 192.168.0.1).
  2. Tìm đến mục Mạng nội bộ (LAN / DHCP Server Settings).
  3. Tại ô Primary DNS (DNS 1), nhập địa chỉ IP của ESP32: 192.168.x.x. Ô Secondary DNS (DNS 2) có thể để trống hoặc điền 9.9.9.9 / 1.1.1.1 dự phòng.
  4. Khuyến khích: Trong mục DHCP Static Lease (Gán IP cố định), hãy gán cố định địa chỉ IP cho ESP32 để IP không bị thay đổi khi mất điện.
  5. Lưu cài đặt và khởi động lại Router (hoặc tắt/bật lại Wi-Fi trên các thiết bị trong nhà để nhận DNS mới).

Cài đặt trên iPhone & iPad (iOS / iPadOS)

  1. Vào Cài đặt (Settings) > Wi-Fi.
  2. Nhấn vào biểu tượng chữ (i) màu xanh cạnh mạng Wi-Fi bạn đang kết nối.
  3. Cuộn xuống dưới chọn mục Định cấu hình DNS (Configure DNS) > Chuyển từ Tự động (Automatic) sang Thủ công (Manual).
  4. Xóa các DNS cũ, nhấn Thêm máy chủ (Add Server) và nhập IP: 192.168.x.x > Nhấn Lưu (Save) ở góc trên bên phải.

Cài đặt trên điện thoại Android

  1. Vào Cài đặt > Kết nối / Mạng & Internet > Wi-Fi.
  2. Nhấn vào biểu tượng Bánh răng (hoặc nhấn giữ tên mạng Wi-Fi) > Chọn Nâng cao / Sửa đổi mạng.
  3. Chuyển Cài đặt IP (IP settings) từ DHCP sang Tĩnh (Static).
  4. Nhập DNS 1: 192.168.x.x, DNS 2: 9.9.9.9 > Nhấn Lưu.

Cài đặt trên Máy tính Windows (10 & 11)

  1. Mở Settings (phím tắt Win + I) > Chọn Network & internet > Chọn Wi-Fi (hoặc Ethernet).
  2. Nhấp vào mạng đang kết nối > Cuộn tới mục DNS server assignment > Nhấn nút Edit.
  3. Chuyển sang Manual, gạt bật mục IPv4.
  4. Tại ô Preferred DNS, nhập: 192.168.x.x > Nhấn Save.

Cài đặt trên Máy tính macOS

  1. Mở Cài đặt hệ thống (System Settings) > Chọn mục Network (Mạng) > Chọn Wi-Fi (hoặc Ethernet).
  2. Nhấn nút Details... (Chi tiết...) bên cạnh mạng Wi-Fi đang kết nối.
  3. Chọn thẻ DNS ở thanh bên trái > Nhấn nút dấu cộng (+) bên dưới danh sách DNS Servers.
  4. Nhập địa chỉ IP: 192.168.x.x > Nhấn OK để lưu cấu hình.
